# ✈️ 한손 비행기

휴대폰을 세로로 들고 **엄지 하나**로 플레이하는 슈팅 게임입니다. `plane.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 조작법
| 동작 | 방법 |
|---|---|
| 이동 | 화면 아무 곳이나 누른 채로 손가락을 움직이면 비행기가 따라옵니다 (손가락이 비행기를 가리지 않아요) |
| 발사 | 손가락을 대고 있는 동안 자동 발사 |
| 폭탄 | 화면을 빠르게 두 번 탭 (폭탄 아이템이 있을 때) |
| 일시정지 | 오른쪽 위 `II` 버튼 · 다른 앱으로 전환하면 자동 정지 |

데스크톱에서는 방향키/WASD로 이동, Space로 폭탄, P로 일시정지할 수 있습니다.

## 아이템
🔵 더블샷 · 🟢 보호막 · 🟡 폭탄 · 🩷 생명

45초마다 보스가 등장하고, 연속 격추 시 콤보 보너스가 붙습니다. 최고 점수는 기기에 저장됩니다.

# 🏙️ 손안의 도시

휴대폰 세로 화면에 맞춘 심시티 스타일 도시 건설 게임입니다. 쿼터뷰(아이소메트릭) 입체 그래픽으로, 건물은 높이와 음영이 있는 블록으로 그려지고 시점을 90°씩 돌려 볼 수 있어요. `city.html`을 브라우저로 열면 바로 플레이할 수 있고, 외부 라이브러리 없이 한 파일로 동작합니다. 게임은 자동으로 저장되고(10초마다, 앱 전환 시), 다른 앱으로 전환하면 자동 일시정지됩니다.

## 조작법
| 도구 | 방법 |
|---|---|
| 👆 정보 | 한 손가락으로 끌면 화면 이동, 탭하면 그 칸의 정보(전기·수도·도로·땅값·공해·치안·서비스 범위) |
| 🛣️ 도로 · 🏠🏬🏭 구역 · 🌳 공원 · 🌲 나무 · 🚜 철거 | 끌어서 선(도로)·사각형으로 그리기. 놓기 전에 칸 수와 비용이 표시돼요. 이때 화면 이동은 두 손가락 |
| ⚡ 발전소 · 💧 급수탑 · 🚓 경찰서 · 🚒 소방서 · 🏫 학교 · 🏥 병원 | 탭하면 반투명 미리보기와 확인 바가 뜨고, 다른 칸을 탭해 옮긴 뒤 ✓로 짓습니다. 도구를 고른 동안 건물이 반투명해져 뒤쪽 땅이 보여요 |
| 확대·축소 · 회전 | 두 손가락 벌리기/오므리기 또는 오른쪽 아래 +/−, ↻ 버튼으로 시점 90° 회전 |
| 시간 | 상단 ⏸ 일시정지, ▶ 버튼을 누를 때마다 1×→2×→3× |

데스크톱에서는 마우스 왼쪽 끌기로 그리기, 오른쪽 끌기로 이동, 휠로 확대, 숫자키 1~0으로 도구 선택, Space 일시정지, R 회전, B 철거, Q/Esc 정보 도구를 쓸 수 있습니다.

## 도시가 자라는 조건
- 구역(주거 R · 상업 C · 공업 I)은 **도로에서 2칸 안** + **전기** + **수도**가 모두 있고 그 종류의 **수요**가 플러스일 때 건물이 들어서고 1→2→3단계로 커집니다. 조건이 빠지면 칸 위에 ⚡💧🛣️ 표시가 깜빡이고 건물이 줄어듭니다. 빈 터의 🏭(공해)·😕(치안)·📉(수요 없음) 표시는 아무도 오지 않는 이유를 알려 줍니다.
- ⚡ 전기는 발전소에서 **붙어 있는 도로·건물**을 따라 흐르고, 전기가 통하는 도로에서 **2칸 안**의 건물에도 들어갑니다. 발전소 하나가 300을 공급하고(주거 1단계 1, 2단계 2, 3단계 4, 공공건물 2~4) 모자라면 공공건물부터, 그다음 발전소에서 가까운 순으로 공급됩니다. 💧 급수탑은 전기가 닿으면 반경 8칸에 물을 줍니다.
- 📈 수요: 일자리가 주민보다 많으면 주거 수요↑, 주민이 많으면 상업·공업 수요↑. 세율이 높으면 수요와 행복도가 떨어집니다. 상단의 R·C·I 막대와 📊 통계에서 확인할 수 있어요.
- 🏭 공업과 발전소는 공해를 내 주변 땅값을 떨어뜨리고, 🌳 공원·🌲 나무·🏫 학교·🏥 병원·🚓 경찰서·물가는 땅값을 올립니다. 땅값이 높을수록 집이 크게 자라고, 상업·공업이 3단계가 되려면 학교 범위가 필요합니다.
- 🔥 화재는 4년째부터 가끔 일어나 옆 칸으로 번집니다. 소방서 범위 안이면 빨리 꺼지고, 밖이면 건물이 잔해(🧱)가 되어 철거해야 합니다. 공장은 불이 더 잘 납니다.
- 💰 매달 세금이 들어오고 도로(칸당 0.5)·공공건물 유지비가 나갑니다. 잔고가 -5,000 아래로 떨어지면 구제금융(최대 3회)을 받고 그 뒤엔 파산입니다.

## 건물과 비용
| 건물 | 비용 | 유지비/월 | 효과 |
|---|---|---|---|
| 🛣️ 도로 | 20 (물 위 다리 60) | 0.5 | 접근성 · 전기 전달 |
| 🏠 주거 / 🏬 상업 / 🏭 공업 | 40 / 60 / 60 | – | 주민 8·24·60명 / 일자리 6·18·45 / 10·30·70 |
| ⚡ 발전소 (2×2) | 2,500 | 40 | 전력 300 공급, 공해 |
| 💧 급수탑 | 600 | 10 | 반경 8칸 급수 |
| 🌳 공원 | 120 | 3 | 반경 4칸 땅값↑ 공해↓ |
| 🚓 경찰서 / 🚒 소방서 | 900 | 30 | 반경 9칸 치안 / 화재 예방·진압 |
| 🏫 학교 (2×2) | 1,200 | 45 | 반경 11칸 교육 |
| 🏥 병원 (2×2) | 1,800 | 60 | 반경 11칸 건강·행복 |
| 🌲 나무 / 🚜 철거 | 15 / 10 | – | 공해 흡수 / 제거 |
