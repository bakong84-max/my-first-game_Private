# 🐾 냥냥 테트리스

고양이 얼굴 블록으로 즐기는 테트리스 게임입니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 조작법
| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↑ / X | 회전 |
| Z | 반대 방향 회전 |
| ↓ | 천천히 내리기 |
| Space | 바로 내리기 |
| C / Shift | 보관 |
| P / Esc | 일시정지 |

모바일에서는 화면 아래 터치 버튼으로 조작할 수 있습니다.

## 고양이 종류
회색냥(I) · 치즈냥(O) · 까망냥(T) · 하양냥(S) · 고등어냥(Z) · 러블냥(J) · 샴냥(L)

# ✈️ 한손 비행기

휴대폰을 세로로 들고 **엄지 하나**로 플레이하는 슈팅 게임입니다. `plane.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 조작법
| 동작 | 방법 |
|---|---|
| 이동 | 화면 아무 곳이나 누른 채로 손가락을 움직이면 비행기가 따라옵니다 (손가락이 비행기를 가리지 않아요) |
| 발사 | 손가락을 대고 있는 동안 자동 발사 |
| 폭탄 | 화면을 빠르게 두 번 탭 (폭탄 아이템이 있을 때) |
| 일시정지 | 오른쪽 위 `II` 버튼 · 다른 앱으로 전환하면 자동 정지 |

데스크톱에서는 방향키/WASD로 이동, Space로 폭탄, P로 일시정지할 수 있습니다.

## 아이템
🔵 더블샷 · 🟢 보호막 · 🟡 폭탄 · 🩷 생명

45초마다 보스가 등장하고, 연속 격추 시 콤보 보너스가 붙습니다. 최고 점수는 기기에 저장됩니다.

# 🎣 바다낚시 3D

배 위에서 바다를 향해 찌를 던지는 3D 낚시 게임입니다. `fishing.html`을 브라우저로 열면 바로 플레이할 수 있어요. (3D 엔진 three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

**크고 무거운 물고기일수록 점수가 높습니다.** 점수 = 무게(kg)^1.3 × 20 — 500g 전갱이는 8점, 10kg 농어는 약 400점, 100kg 참다랑어는 약 8,000점입니다. 5분 동안 최대한 높은 점수를 노려 보세요.

## 그래픽
- 수면은 게르스트너 파도(뾰족한 마루, 넓은 골)로 움직이고, 거울 카메라로 하늘·섬·배를 실시간 반사하며, 수면 아래 장면을 깊이와 함께 따로 그려 굴절·수심에 따른 빛 흡수(빨강이 먼저 사라짐)·해안과 선체에 닿는 포말·역광 마루의 투과광을 계산합니다. 절차 생성 노멀맵 세 겹으로 잔물결과 태양 반짝임을 표현합니다.
- ACES 톤매핑과 블룸(three.js 후처리 애드온), MSAA, 태양 렌즈 플레어, 비네팅을 적용했습니다.
- 물고기는 젖은 광택(클리어코트)과 비늘 범프맵이 있는 물리 기반 재질이고, 릴 싸움 중에는 화면 상단 수중 카메라 창에 걸린 물고기가 빛줄기와 함께 비칩니다.
- 구름은 부드러운 스프라이트로 시간대에 따라 색이 변하고, 물보라는 파티클로 튑니다.
- 물고기는 가속·감속하며 선회할 때 몸을 기울이고, 오르내릴 때 머리를 들거나 숙입니다. 꼬리 박자는 속도와 몸길이에 따라 달라지고, 전갱이·고등어는 무리를 지어 다닙니다.
- 느린 기기에서는 `fishing.html?low`로 열면 반사 해상도를 낮추고 블룸·그림자를 끕니다.

## 바다와 시간
- 하늘에는 갈매기 14마리가 원을 그리며 날갯짓과 활공을 번갈아 하고 가끔 수면으로 급강하하며 울음소리를 냅니다.
- 수평선에는 섬 9개가 보입니다. 기와 지붕·창문·굴뚝이 있는 집, 첨탑 교회, 창고, 방파제 끝 등대, 정박한 어선이 있는 항구섬, 아파트 단지와 타워가 있는 큰섬, 밤이면 등대가 깜빡이는 등대섬·바위섬, 쌍둥이섬, 큰섬 등이 배 위치와 방향에 맞춰 나타납니다.
- 한 라운드(5분) 동안 게임 시간이 18시간 흐릅니다. 출항 시간을 새벽(05:30)·한낮(12:00)·밤(20:00) 중에서 고를 수 있어요. 하늘·물빛·안개·조명이 시간에 따라 바뀌고, 밤에는 별과 달, 갑판 작업등, 마을 불빛, 전자찌 불빛이 켜집니다.
- 시간대에 따라 잘 잡히는 물고기가 다릅니다. 농어·우럭·돗돔은 밤에, 방어·부시리·참돔·감성돔·전갱이는 새벽과 해질녘에, 고등어·참다랑어·광어는 낮에 더 자주 나타납니다.

## 소리
효과음과 배경음악 모두 외부 파일 없이 WebAudio로 실시간 합성됩니다. BGM은 낮(잔잔한 장조 아르페지오), 밤(느린 단조), 릴 싸움(빠른 긴장 루프, 장력이 높을수록 거칠어짐), 이동(가벼운 리듬) 4개 트랙이 상황에 따라 마디 단위로 바뀌고, 파도 소리가 깔립니다. 오른쪽 위 🎵(BGM)·🔊(효과음)·📳(진동) 버튼으로 각각 끌 수 있고 설정은 기기에 저장됩니다. 진동은 입질·챔질·릴 감기(장력이 높을수록 강하게)·물고기가 달아날 때·줄 끊김·포획에 울립니다. 아이폰·아이패드 브라우저는 진동 API가 없어 울리지 않고, 안드로이드에서도 다른 사이트 안의 프레임(claude.ai 아티팩트 등)에서 열면 브라우저가 진동을 막으므로 `fishing.html`을 직접 열어야 울립니다. 브라우저 정책상 첫 터치 이후 소리가 납니다.

## 지도와 낚시 포인트
왼쪽 아래 미니맵(또는 M 키)을 누르면 지도가 열립니다. 포인트를 고르고 출발하면 배가 방향을 틀어 이동하며, 이동 중에도 시간은 흐릅니다(거리별 5~20초). 찌를 거둔 상태에서만 이동할 수 있어요.

| 포인트 | 주요 어종 |
|---|---|
| ⚓ 항구 앞바다 | 전갱이 · 고등어 · 우럭 |
| 🪨 갯바위 포인트 | 우럭 · 감성돔 · 농어 |
| 🏖️ 모래톱 | 광어 · 전갱이 |
| 🌊 섬 사이 물길 | 참돔 · 농어 · 방어 |
| 🌀 먼바다 조류대 | 방어 · 부시리 · 참다랑어 · 만새기 · 청새치 |
| 🕳️ 심해 절벽 | 돗돔 · 청상아리 · 참다랑어 |

## 캐릭터
캐릭터는 모두 2D 애니메이션입니다. 시작 화면과 포획 장면에는 애니메이션풍 일러스트 초상(평상시·기쁨 표정)이 나오고, 게임 중에는 머리·몸·양팔이 따로 움직이는 종이인형 방식의 2D 캐릭터가 배 위에서 던지고 감고 기뻐합니다. 모두 캔버스 벡터로 기기에서 바로 그려지며 외부 이미지는 없습니다.

| 캐릭터 | 콘셉트 | 특성 | 포획 세리머니 |
|---|---|---|---|
| 🎣 만수 | 노련한 낚시광 중년 아저씨. 버킷햇에 낚시바늘 핀, 희끗한 수염, 체크 셔츠와 다주머니 조끼 | 챔질 여유 40% 증가, 물고기가 25% 빨리 지침 | 양팔 벌려 호탕하게 |
| 💪 태양 | 힘세고 잘 챙긴 청년. 머리 위 선글라스, 민소매, 넓은 어깨와 굵은 팔 | 줄 강도 20%, 릴 감기 15% 빠름 | 한 손으로 치켜들고 주먹 펌프 |
| 🌺 세라 | 물고기가 잘 붙는 섹시한 베이글 아가씨. 뒤로 쓴 올리브 캡, 긴 적갈색 웨이브 머리, 초록 눈과 주근깨, 올리브 탱크탑과 드러난 허리, 카모 반바지, 허벅지까지 오는 녹색 장화 | 입질 40% 빨리 옴 | 한 손으로 들고 골반 흔들기 |
| 🎀 루나 | 희귀종을 잘 찾는 어리고 귀여운 여자아이. 양갈래 리본 머리, 큰 눈, 노란 레인코트 | 희귀 어종 2.5배 등장 | 두 손으로 번쩍 들고 폴짝폴짝 |

## 조작법
| 단계 | 방법 |
|---|---|
| 던지기 | 화면을 꾹 눌러 힘을 모으고, 놓으면 던집니다. 누른 채 좌우로 움직이면 방향 조절 |
| 챔질 | 찌가 쑥 들어가며 **!** 표시가 뜨는 순간 탭 (너무 빨리 누르면 물고기가 도망가요) |
| 릴 감기 | 오른쪽 아래 릴 손잡이를 손가락으로 시계 방향으로 빙글빙글 돌리면 줄이 감깁니다(초당 약 1.3바퀴가 100%). 빨리 돌릴수록 빨리 감기지만 장력도 빨리 오릅니다. 물고기가 달아날 때(🐟💨)는 손을 멈춰 장력을 낮추세요. 장력이 빨간 구간을 넘으면 줄이 끊어집니다. 데스크톱은 Space를 누르고 있으면 일정 속도로 감깁니다 |
| 회수 | 입질이 없으면 0.7초 이상 꾹 눌러 찌를 거둡니다 |
| 포인트 이동 | 왼쪽 아래 미니맵(M 키)을 눌러 지도를 열고 포인트를 선택한 뒤 출발 |
| 일시정지 | 오른쪽 위 `II` 버튼 · 다른 앱으로 전환하면 자동 정지 |

데스크톱에서는 Space 누르기/놓기, ← → 방향 조절, P 일시정지를 쓸 수 있습니다.

## 어종
일반: 전갱이 · 고등어 · 우럭 / 희귀: 광어 · 감성돔 · 참돔 · 농어 / 영웅: 방어 · 부시리 · 만새기 / 전설: 참다랑어 · 돗돔 · 청새치(최대 400kg) · 청상아리(최대 300kg)

청새치와 청상아리, 만새기는 먼바다 조류대와 심해 절벽에서만 나오고 걸리면 수면 위로 자주 뛰어오릅니다.

어종마다 체형과 무늬가 다르게 생성됩니다(고등어 물결무늬, 참돔 푸른 점, 방어 노란 띠, 광어 눈점 등). 무거운 물고기일수록 더 세게, 더 오래 버팁니다. 물고기가 달아나는 동안 장력을 유지하면 체력이 떨어져 "지쳤다!" 상태가 되고, 그때 감으면 훨씬 수월해요. 최고 점수와 역대 최고 무게는 기기에 저장됩니다.

`fishing.html?gallery`로 열면 모든 어종을 한눈에 볼 수 있고, 느린 기기에서는 `fishing.html?low`로 열면 그림자를 끈 저사양 모드로 실행됩니다.
